# Tales of Arise Vortex Extension

### Supports mode types

- Engine Injector
    - Dumps the mod contents in the game root directory 
- PAK (UE4)
    - Installs pak files to directory: `Tales of Arise\Arise\Content\Paks\~mods`
- USM (UE4)
    - Installs usm files to directory: `Tales of Arise\Arise\Content\Binaries\Movie\Animation`
